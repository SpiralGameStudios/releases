# SpiralGameStudios — releases

Public release assets for SpiralGameStudios games, consumed by the SGS launcher.

- Each game version is a release `<game>-<platform>-<version>` holding content-addressed files (named by sha256) and `manifest-<platform>.json`.
- The release `<game>-latest` holds `latest-<platform>.json`, the pointer the launcher reads first; it is uploaded last, so a version becomes visible only when complete.
- Nothing here is meant to be browsed by hand: install the SGS launcher and press Play.
